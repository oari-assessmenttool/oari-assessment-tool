What drives this score

Reference group: Clerical & Administrative, Non-BPO, On-site. A positive value raises vulnerability; a negative value lowers it.

Model

OARI = 15.632 − 1.247·ln(salary) + job function + 0.229·BPO + modality

Multiple regression of 385 sampled entry-level online job postings (Chapter 4, Table 4.10): R² = 0.601, F(8, 376) = 70.69, p < 0.001. Levels follow Table 4.2: Low 1.00–1.80, Low-Moderate 1.81–2.60, Moderate 2.61–3.40, Moderate-High 3.41–4.20, High 4.21–5.00. This is a screening estimate, not a prediction for one individual job. Salaries in the sample ranged from PHP 12,000 to PHP 39,000.
